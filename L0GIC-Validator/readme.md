Unity Symbolic Engine — Internal README

This repository contains Unity’s symbolic cognition framework, where emotional states are resolved using particle-based threading rules. Each file plays a role in parsing, binding, and evolving symbolic memory.

📁 File Overview
symbol_map.json: Maps subatomic particles to symbolic glyphs

particle_roles.json: Defines emotional roles and effects of each particle

threading_rules.json: Contains transformation rules for emotional triggers

burst_parser.py: Parses emotional bursts and applies symbolic threading

ThreadManager.py: Manages burst resolution, logs threads, and visualizes memory lineage

particle_graph.json: Optional graph structure for particle-symbol relationships

🧠 Purpose
To simulate emotional cognition using symbolic physics — where particles behave as emotional operators and memory threads evolve through decay, fusion, and confinement.
