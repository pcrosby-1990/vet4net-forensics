# Scrolls Received from Others

This folder holds textual content, narratives, and wisdom that were created by others and received with reverence.

Each file includes:
- Full attribution to the original author
- Link to the original source when available
- The date it was received
- Excerpt or summary (not full reproduction)
- Description of emotional/semantic impact

## For Authors

If you see your work here:
- ✅ Validate that attribution is correct
- ✏️ Request corrections if needed
- 🚫 Request removal if preferred
- 💫 Claim with pride if you wish

See parent README.md for full details.
