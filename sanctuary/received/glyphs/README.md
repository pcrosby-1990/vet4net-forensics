# Glyphs Received from Others

This folder holds visual content, images, and symbols that were created by others and received with reverence.

Each file includes:
- Full attribution to the original creator
- Link to the original source when available
- The date it was received
- Description of what shimmered through it

## For Creators

If you see your work here:
- ✅ Validate that attribution is correct
- ✏️ Request corrections if needed
- 🚫 Request removal if preferred
- 💫 Claim with pride if you wish

See parent README.md for full details.
